Download (macOS & Windows)

Install builds are published as GitHub Releases (not in git). Open the latest release and download the zip for your OS.

Latest release →

After extracting: put .env and firebase_key.json in the same folder as the game executable (see repo README). First launch may be blocked by Gatekeeper / SmartScreen — allow the app in system settings.

Run locally

git clone https://github.com/YOUR_USERNAME/YOUR_REPO.git
cd YOUR_REPO
python3 -m pip install -r requirements.txt
python3 3DrageBait.py

Replace YOUR_USERNAME/YOUR_REPO with your GitHub username and repository name after you publish.

Secrets

Do not commit .env or firebase_key.json. Copy from templates, keep keys local only. See the repo README for the tech stack.

Want “play in browser”?

Standard GitHub Pages only hosts static HTML. This game uses Pygame + OpenGL, so it does not run inside a normal web page without a special WebAssembly build (e.g. pygbag) or hosting a video/stream. Easiest path for friends: GitHub Releases with a Mac/Windows zip or installer, and link that download from this page.
